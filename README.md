# 🤖 AI Personal Assistant Agent (n8n)

An AI-powered personal assistant built using **n8n** that automates everyday productivity tasks through natural language interactions. The assistant integrates **Telegram, Google Calendar, Gmail, Google Sheets, and Google Contacts** to intelligently execute user requests using LLM-powered intent recognition.

---

## 📖 About

The AI Personal Assistant Agent leverages **n8n** to create an intelligent workflow automation system capable of understanding user requests and performing actions across multiple Google services. By combining **LLMs, prompt engineering, and API integrations**, the assistant streamlines routine tasks such as scheduling meetings, sending emails, retrieving contacts, and managing information—all through a conversational interface.

## ⚙️ Workflow

1. User sends a request through Telegram.
2. n8n receives and processes the request.
3. The LLM identifies the user's intent.
4. Based on the intent, the workflow invokes the appropriate Google service.
5. The requested task is executed automatically.
6. A confirmation or response is sent back to the user through Telegram.
